# Feather Pace: magazyn plików do publikacji

To repozytorium jest publiczne i służy tylko jako tymczasowy magazyn plików (filmy, zdjęcia) do postów marki Feather Pace.

- Narzędzia do planowania postów (Buffer, Metricool) pobierają plik spod publicznego adresu. Stąd go dostają.
- Plik trafia tu dopiero po akceptacji publikacji przez Bruna i jest usuwany po opublikowaniu posta.
- Nie ma tu kodu strony ani gry (te są w prywatnym repozytorium `featherpace-site`).
- Nie wgrywać tu niczego poufnego: haseł, kluczy, danych klientów, niepublikowanych planów.

Układ:

- `media/RRRR-MM/` – pliki do zaplanowanych postów (puste, gdy nic nie czeka na publikację)
